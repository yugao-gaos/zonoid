# Task: Add JSDoc Documentation

The file `bench/sandbox/input.js` contains 3 exported utility functions with no documentation.
Add JSDoc comments to all 3 functions and write the documented version to `bench/sandbox/solution.js`.

Requirements:
- Each function must have a JSDoc block (`/** ... */`) immediately above it
- Each `@param` must be documented with type and description
- Each function must have a `@returns` tag with type and description
- Include a one-line summary at the top of each JSDoc block (before any tags)
- Keep the function implementations identical — only add/modify documentation

The 3 functions are: `formatDate`, `truncate`, `deepMerge`.

Export: `module.exports = { formatDate, truncate, deepMerge }` (same as input).

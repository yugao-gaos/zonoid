# Self-Learn

Use this canonical skill for self-learning work. Select the mode that matches the task and read only
that reference:

- [judge.md](references/judge.md) for attempt review, single-attempt gates, metric-aware verdicts,
  and feature-vs-main merge behavior.
- [edge-judge.md](references/edge-judge.md) for note/task edge adjudication and duplicate clusters.
- [benchmark.md](references/benchmark.md) for external metric benchmark research.
- [kb.md](references/kb.md) for daytime KB candidate and staleness learning.
- [qa.md](references/qa.md) for nightly QA sweeps and reproducible regression filing.

Planning and optimize-loop behavior lives in
[brain-activation](../brain-activation/SKILL.md), not in this skill.
